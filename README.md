# Grok 英语练习系统

用 Grok 做英语口语陪练的练习方法。这份仓库给出一套完整的上课方式：先测水平，再按只比你现在难一点点的方式练，课后写出学习报告，并把记录保存在笔记里。

适合想用语音真正练口语的人，而不是只把英语听写进聊天框。

## 这份 Skill 做什么

- **先测级，再开练。** 第一次使用先做 3–5 分钟口头小测，判断当前处在哪个 level，之后的对话只比这个基础难一点点。
- **先选定口音。** 英音或美音选一种，示范、纠音和学习报告里的国际音标都按同一种来，不混着练。
- **用语音对话，不要用语音听写。** 语音对话是直接开口说话，才能听到发音和语调并及时纠正；语音听写只是把话转成文字发到聊天里，听不到声音，不能用来练口语。
- **按生活主题练。** 主题按使用频率排列，例如吃饭、交通、购物、看病、面试、租房、旅行、社交闲聊。一次只进入一个具体情境。
- **按遗忘曲线自然复习。** 新学的词和表达会在第 1 天、第 2–3 天、第 7 天、第 14–16 天，在之后的对话里再碰到，而不是单独做闪卡。
- **课后出学习报告。** 报告默认发到和英语教练的对话里。如果已经连接微信，也可以发到微信。生词会标注国际音标。

完整规则见：[Grok英语练习系统-用户学习Skill.md](./Grok英语练习系统-用户学习Skill.md)

## 学习记录放在哪里

不另做网站。每次练完，把当天的练习写成一篇笔记。

- 如果正在使用 Obsidian，记录保存在仓库里的「英语学习」文件夹。
- 如果没有 Obsidian，会先请你建一个专门的文件夹，确认路径后再写入。

每篇笔记会记下：当天学到的词汇和表达（含国际音标）、按遗忘曲线安排的复习时间，以及这次练习的日期、时长、主题和情境。记录根据当次学习报告来写，不会自动去翻聊天记录。

## 怎么用

把这份 Skill 提供给负责陪练的 Grok（或英语教练），按文档从头开始：先选口音，再用语音对话完成口测，然后进入对应水平的练习。
