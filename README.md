# Grok 英语练习系统

这是一份给使用者的指引：怎么用这份 Skill，和 Grok 做英语口语陪练。

完整的练习规则在 [Grok英语练习系统-用户学习Skill.md](./Grok英语练习系统-用户学习Skill.md)。下面只说明你要怎么开始、练习时会发生什么，以及学习记录会保存在哪里。

## 你需要准备什么

- 一个可以使用的 Grok（建议开通并能语音对话）
- 用**语音对话**来练，不要用语音听写
- 可选：Obsidian。用来保存每次练习的笔记。没有的话，也可以先建一个普通文件夹

语音对话是直接开口和教练说话，对方能听到你的发音和语调，并及时纠正。语音听写只是把你说的话转成文字发到聊天里，听不到声音，不能用来练口语。

## 怎么开始

1. 打开本仓库里的 [Grok英语练习系统-用户学习Skill.md](./Grok英语练习系统-用户学习Skill.md)，把它提供给负责陪练的 Grok（或英语教练）。
2. 第一次使用时，先选择要练**英音**还是**美音**。选定后，示范、纠音和学习报告里的国际音标都会按这一种来，不会混着练。中途若要更换，再主动说明即可。
3. 接着用语音对话做一次大约 3–5 分钟的口头小测，不用写成试卷。口测大致包括：
   - 用英语做大约 20 秒自我介绍（你是谁、在哪、最近在忙什么）
   - 现场应对 2 个日常情境，例如在咖啡店点单、向司机说明目的地
   - 再回答一个稍难一点的追问（比如为什么、如果不行怎么办）
4. 教练会根据你的流利度、用词，以及能不能听懂追问，判断你当前的水平（L1 入门到 L4 流利），然后从对应层级开始练。之后的对话只会比你现在的水平难一点点。
5. 如果正在使用 Obsidian，第一次保存记录前，会在你的仓库里使用（或新建）一个名为「英语学习」的文件夹。如果没有 Obsidian，教练会先请你建一个专门的文件夹，确认路径后再写入。不要把记录只留在临时目录里。

## 练习时会怎么进行

- 按生活里常用的主题来练，例如吃饭、交通、购物、看病、面试、租房、旅行、社交闲聊。一次只进入一个具体情境。
- 不只改语法，也会纠正发音、重音和语调，并请你跟读确认。
- 对话里会穿插需要展开的问题，让你多说几句，而不是只回答是或不是。
- 一段练完后，常用刚刚学过的词即兴做一个小场景，让你现场应对。
- 新学的词和表达不会只出现一次。按遗忘曲线，大约在第 1 天、第 2–3 天、第 7 天、第 14–16 天，会在之后的对话里再碰到它们，而不是单独做闪卡。能自己比较准确地用出来，才算记住。

## 课后的学习报告和记录

每天语音练习结束后，会生成一份学习报告，默认发到你和英语教练的对话里。因为不是每位用户的 Grok 都已连接微信，所以默认不发到微信；如果你已经连接微信，也可以让报告发到微信。

报告里会包括：练习日期、时长、主题和情境、本次口音、练了什么、纠正要点、生词表，以及下次该复习的内容和下一课建议。生词会标注国际音标（IPA），并和你选择的口音一致。

报告生成后，教练会把这一次练习写成一篇笔记，存进上面说的那个文件夹。记录根据当次报告来写，不会自动去翻聊天记录。

每篇笔记通常包括：

- 当天学到的词汇和表达（英文、国际音标、中文意思、主题或情境、首次学会的日期和备注）
- 按遗忘曲线安排的复习时间，以及是否已经能主动用出
- 本次练习的日期、时长、主题和情境，还有课堂摘要、纠正要点和下次建议
